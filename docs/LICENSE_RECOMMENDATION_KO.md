# 프로젝트 라이선스 권고

자체 작성 코드에는 **MIT**를 권고한다. 짧은 허용형 라이선스로 사용·수정·재배포를 허용하면서 저작권 및 허가 고지 보존을 요구한다. [OSI의 MIT 원문](https://opensource.org/license/mit)을 확인했다.

`release/LICENSE.MIT-DRAFT.txt`는 검토용 초안이며 아직 저장소 전체에 효력이 있는 LICENSE로 적용하지 않았다. 사용자가 승인하면 저작권 표시를 확인하고, 상단 초안 안내를 제거한 원문을 공개 스냅샷 루트 `LICENSE`로 두면 된다. 이는 사용자 결정 전 공개 허가를 받았다는 의미가 아니다.

외부 MIT 앱·기존 예제·의존성의 개별 라이선스는 그대로 보존한다. axe-core의 MPL-2.0과 Apache/BSD 등 타 의존성 고지를 MIT 하나로 대체하지 않는다. Meta/OpenAI API 이용 조건과 모델 결과·영상의 공개 조건도 소프트웨어 라이선스만으로 자동 해결되는 것은 아니다.

공개 전에는 작성자·권리 범위, 운영진의 공식 제출 요구, 포함된 제3자 고지를 함께 확인한다. 이번 릴리스는 공개 push나 법적 적격성 승인을 대신하지 않는다.
