## 음성·자막 동기화

1. 6개 장면, 29개 짧은 발화 단위의 영어 대본을 먼저 확정했다.
2. 로컬 Microsoft Zira Desktop 음성을 새로 생성했다. 외부 TTS/Meta API 호출 없음.
3. 실제 WAV 파형을 10ms 단위로 검사하고 합성기의 단어 이벤트 시각을 수집했다.
4. 첫 시도의 24kHz 및 기본 22.05kHz에서 이벤트 시각이 WAV 길이를 넘는 문제를
   발견했다. 실패 시도는 비공개 작업 폴더에 보존하고 16kHz로 새로 생성했다.
5. 최종 첫 단어 이벤트와 파형 시작의 차이는 최대 20ms였다. 자막은 발화 시작보다
   40ms 먼저, 마지막 유성 구간 뒤 100ms 이내에 끝나도록 배치했다.
6. 긴 발화 1개는 실제 단어 이벤트 경계에서 나눴다. 30개 자막의 내용이 전체
   최종 대본과 일치하고, 겹침·역순·3줄 이상 자막이 없음을 검사했다.
7. 이 확정 음성/자막 길이에 맞춰 화면을 구성했다. 25fps 프레임 양자화 오차는 최대 20ms.
8. 최종 AAC를 다시 PCM으로 추출하여 29개 발화에서 원본 WAV와 비교했다.
   모든 구간의 측정 시간 이동은 0ms(1ms 탐색 간격), 정규화 상관 검사 통과.

사용하지 않았으며, 합성기 이벤트와 실제 파형을 이용한 검증이다.
