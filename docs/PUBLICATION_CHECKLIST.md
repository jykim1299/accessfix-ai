1. Select the project-wide license and confirm the copyright notice. MIT remains
   a proposal in release/LICENSE.MIT-DRAFT.txt, not an active root LICENSE.
2. Review the complete final video, especially synthetic speech quality. Choose
   narration or caption-only and confirm the authenticated portal's media rules.
3. Confirm the participant guide, team identities, exact final fields, rights and
   consent. See SUBMISSION_REQUIREMENTS_KO.md for verified versus unknown items.
4. Approve publication of this exact file list and evidence subset. Start from
   this independent directory; never push the old development Git history.
5. After explicit authorization, create/push a public repository and host the
   selected video. Enter actual URLs, never placeholders, then submit and keep
   the receipt. No remote repository, push, deployment or submission was made.

The snapshot preserves success, rejection and manual-review cases. It excludes
raw authenticated trace ZIPs, original model/network logs, local session tokens
and developer environment files. Original experiments remain in the private
development workspace; public evidence lists transformations and omissions.
