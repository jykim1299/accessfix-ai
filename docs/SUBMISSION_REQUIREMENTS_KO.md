## 실제 제출 필드 확인 상태

포털 공개 응답은 행사 설명을 반환했으며 최종 입력 필드를 노출하지 않았다. Work 설정에서 로컬 브라우저 사용이 비활성화되어 로그인된 폼을 확인하지 못했다. 따라서 아래의 미확인 항목을 실제 필수 필드라고 단정하지 않는다. 공개 페이지의 참가 신청 질문과 프로젝트 최종 제출 질문도 혼용하지 않았다.

| 항목 | 확인 범위 | 현재 준비/남은 확인 |
|---|---|---|
| 트랙·팀원 | 규정상 한 트랙, Indie 최대4명, 대표자의 전체 팀원 식별 확인 | 계정의 정확한 제출 필드·팀원 계정 식별 방식 확인 |
| GitHub 주소 | 최종 제출 필수 여부·공개/비공개 조건 미확인 | 검토된 로컬 스냅샷 준비; 원격 주소는 게시 승인 이후 |
| 데모 영상 | 평가에 영상 품질 포함 확인; 입력 방식·호스팅·형식·용량·언어·길이 제한 미확인 | 사용자가 요청한 180초 이내 MP4/WebM 준비; 이를 공식 제한이라고 표기하지 않음 |
| 프로젝트명·설명 | 최종 필드 이름·글자 수·필수 여부 미확인 | AccessFix AI 설명 초안을 실제 폼 제한에 맞춰 입력 |
| Meta 모델 활용 설명 | Meta AI Tooling 평가 비중 확인; 별도 필드·글자 수 미확인 | 실제 `muse-spark-1.3-contributor` 수리/검증 근거, 저장 결과 재생 명시 |
| 실행 가능한 데모 URL | 필요 여부·로그인/배포 조건 미확인 | 현재는 로컬 실행. 외부 배포 여부를 추정하지 않음 |
| 소스 라이선스 | MIT 필수 조건을 확인하지 못함 | MIT 초안만 유지; 사용자가 최종 선택 |
| 규정·권리 동의 | 규정에 제출물 권리·주최측 이용허락 조항 존재 | 사용자가 최신 원문을 읽고 실제 제출 단계에서 직접 동의 |

운영사 규정은 제3자 권리와 오픈소스 라이선스 준수를 요구한다. 사전 PoC 코드 재사용을 허용받았다고 해석하지 않았으며 기존 프로젝트 경계를 유지한다. 참가자 가이드의 구체적인 신규 개발/재사용 조건은 이번 공개 경로에서 **독립 확인하지 못했다**. 초청 안내에 포함된 최신 참가자 가이드나 운영진 답변이 있다면 제출 전 대조해야 한다. [규정 원문](https://cerebralvalley.ai/e/meta-ai-developer-hackathon/waiver)

## 제출 포털에서 남은 사용자 작업

1. 승인된 참가자 계정으로 공식 제출 포털을 열고 최신 참가자 가이드·최종 필드·제약을 확인한다.
2. 팀 대표/팀원, 트랙, 프로젝트 설명을 실제 필드에 맞춰 확정한다. 개인정보는 공개 소스에 기록하지 않는다.
3. 라이선스와 공개 범위를 결정하고 GitHub·영상 게시를 승인한다. 실제 게시 URL이 생기기 전에는 URL을 만들어 쓰지 않는다.
4. 확인된 영상 형식/호스팅 요건에 맞춰 파일 또는 링크를 제공한다. 저장된 실제 Meta 결과 재생임을 유지한다.
5. 공식 규정 동의와 제출을 사용자가 완료하고, 접수 확인 화면/시각을 보존한다.

이번 문서는 **확인된 공개 요건과 미확인 항목의 구분**이다. 참가자 가이드 전체 또는 로그인된 최종 폼을 확인했다는 의미가 아니다. 확인되지 않은 3분 제한, MP4 필수, 공개 GitHub 필수, 팀 정보 형식 등을 임의로 추가하지 않았다.

로컬 조사 근거는 `artifacts/submission-polish/official-requirements/source-manifest.json`과 해당 공개 HTML 해시에 있다. 전체 공개 문서 사본은 조사 보존용이며 출품 ZIP/새 공개 저장소에 포함할 필요가 없다. 초기 추출 결과와 개선된 추출 결과도 별도로 보존했다.
